# Athletic Rwanda Athlete UI

## Design Read

Mobile-first athlete product for young footballers, with a trust-first health layer and a more expressive performance layer. It should feel like a calm personal record inside a serious national sports system, not like a generic admin dashboard.

## Core Taste

- Design variance: 6
- Motion intensity: 4
- Visual density: 5
- Palette: deep field green, warm light text, one electric mint action accent
- Supporting signals: violet for performance, coral for health attention
- Display type: Space Grotesk
- Interface type: DM Sans
- Shape rule: 22px cards, 13px controls, pill only for status and toggles
- Motion rule: short transitions only; no decorative loops

## Shared Profile Language

All future profiles inherit:

- The same top-level navigation and brand mark
- One accent action color: mint
- Role-specific secondary signal colors
- Page headers with eyebrow, title, description, and feature explanation action
- Clickable feature cards with information modals
- Seeded data that is shared across roles
- Responsive layouts, with the Athlete view designed mobile-first
- Clear privacy language around medical data

## Prototype Boundaries

This is a presentation prototype. Data is local and synthetic. It does not claim to be a production medical system, implement authentication, or connect to a real athlete record.
