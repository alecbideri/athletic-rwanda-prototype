# Athletic Rwanda Prototype

Standalone frontend prototype for the Athletic Rwanda sports intelligence platform.

## Views

- Athlete mobile-first portal
- Ministry national dashboard
- FERWAFA federation control room
- Coach intelligence workspace
- Medical staff workspace

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The prototype uses synthetic JSON data in `src/data/`. No production athlete or medical data is included.
